# Integration Test Folders

This tree holds Business Rule integration tests organized by `setupGroups`.

Folder rule:

- `test/BusinessRule/integration/<setupGroup>/BusinessRule_<Name>.int.test.js`

Use integration tests for workflow-oriented, event-driven, multi-rule, or richer STEP-like execution flows.

Create the `<setupGroup>` folder when the first integration test for that group is added.
