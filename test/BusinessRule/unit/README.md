# Unit Test Folders

This tree holds Business Rule unit tests organized by `setupGroups`.

Folder rule:

- `test/BusinessRule/unit/<setupGroup>/BusinessRule_<Name>.test.js`

Examples:

- `test/BusinessRule/unit/Libraries/BusinessRule_UtilityLibrary.test.js`
- `test/BusinessRule/unit/DataFetchers/BusinessRule_returnValuesJSON.test.js`

Create the `<setupGroup>` folder when the first test for that group is added.
